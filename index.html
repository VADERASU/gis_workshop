County map workshop

Find a story in county data.

Start here

Your task is to build a map that colors US counties by a measure you choose. The blank map is your starting point. Your coding agent will build it; you'll check the results.

  1. Choose your data. Start with unemployment in 2016 and ask: where were rates highest? Other options are broadband access, mask use, or your own county-level CSV with county identification codes (FIPS).
  2. Open your coding agent in this project folder. If you're using an installed Claude Code, open the editor's terminal and run claude. Paste the prompt below into the agent. It uses unemployment and D3, one of the workshop's mapping libraries; change those choices if you wish.

    Build a county map in this starter project using D3 and data/unemployment-2016-county.csv. Map the unemp column as a percentage and match counties using the fips column.

    Use plain JavaScript and browser ES modules. No bundler, npm install, or framework. Ask before adding another dependency. Update the dataset settings, fill in the map and legend functions, and connect them so the map appears.

    Before writing code, explain in two sentences how you'll match the county codes and preserve leading zeros. Include a legend and county names and values on hover. Show missing data separately from zero. Report how many counties matched and list unmatched codes. Explain the color cutoffs.

    For a different dataset, give the agent its filename, the column to map, and the header plus four real rows copied from the CSV.
  3. View and check your map. When the agent finishes, refresh this page. You should see colored counties and a legend. If it stays blank, tell the agent what you see and ask it to fix the problem. Compare a few county values with the CSV and review any unmatched codes.
  4. Make a reporting judgment. Check the measure's meaning, units, and year. Use rates for fair comparisons across population sizes. Ask the agent to try different color cutoffs: does the apparent pattern change? Write a headline supported by the data, then ask the agent to add it, cite the source and year, and remove these instructions.
